# 📱 App Maker

**App Maker** é uma aplicação web interativa que permite criar visualizações personalizadas de aplicativos, com nome, URL, ícone, captura de tela e descrição. Você pode gerar uma prévia no estilo de celular e publicar seus apps para visualização pública. A interface também inclui um sistema de chat interativo e um embed de site responsivo.

## 🚀 Funcionalidades

- ✅ Preencher detalhes de um app: nome, URL, ícone, imagem e descrição
- ✅ Upload de ícone e captura de tela via URL ou arquivo
- ✅ Visualização dinâmica no estilo celular
- ✅ Botão de “GET” simulando download do app
- ✅ Lista de apps publicados com carregamento automático
- ✅ Janela embutida com pré-visualização do site do app
- ✅ Chat integrado estilo suporte ao cliente

## 💡 Como usar

1. Clone ou baixe este repositório:
   ```bash
   git clone https://github.com/alemaodacapa/app-maker.git
   ```
2. Abra o arquivo `index.html` no navegador.
3. Preencha os dados do app e visualize a prévia ao vivo.
4. Publique e veja seus apps aparecerem na seção “Published Apps”.
